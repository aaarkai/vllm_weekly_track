# Weekly Release Report for vllm-project/vllm (2026-11-20)

This week merged 681 PRs from 316 contributors. Key areas: features 0, fixes 129, performance 64.

## Executive Summary

本周发布未包含独立功能增强条目，重点集中在性能、模型与硬件适配及稳定性修复。MiniMax-M3.1-Flash 通过 CuTe DSL 在 GB300 上优化 decode，报告最高 1.45 倍提升；EPLB 支持异构 DeepSeek V4/V4.1 DSpark draft experts；DeepSeek-V4.1 新增 A100（SM80）与 H100（SM90）支持；ECTieringConnector 为 encoder cache 增加文件系统分层。修复覆盖 KV Offload、Multimodal、kernel、ROCm、Rust Frontend、安全校验及启动/退出路径，并处理量化、投机解码与缓存一致性问题。

升级方面，Python 3.14 已成为镜像与 CI 的默认版本，建议升级前验证 Python 3.14 兼容性，并针对目标模型与硬件组合执行回归测试。本周未明确列出破坏性变更；使用 KV Offload、多模态处理器或自定义 kernel 的部署应关注相关修复后的行为差异。
