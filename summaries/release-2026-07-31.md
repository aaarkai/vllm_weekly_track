# Weekly Release Report for vllm-project/vllm (2026-07-31)

This week merged 331 PRs from 169 contributors. Key areas: features 5, fixes 68, performance 25.

## Executive Summary

本周发布重点为新增 Kimi K3 模型支持，包含模型文件、kernel、deepgemm 适配及工具调用 ID 修复；同时为 GLM-5.2 提交了 Blackwell decode 优化，但该优化已回退。性能方面，ReplaySSM 通过缓存 SSM 输入加速 Mamba2 标准 decode，DeepSeek-V4 自适应 topk 宽度带来约 1.0% 端到端吞吐提升，并减少 448 MiB GPU 内存占用。修复覆盖 ROCm、XPU、CPU 等后端，涉及 MoE kernel、KV offload、multimodal、FP8/量化推理、CUDA graph 及 cgroup 内存限制等多项问题。另有 TML inkling 在 ROCm 上启用、Rubin sm_107 支持等硬件相关更新。未发现需要特别提示的破坏性变更或升级注意事项。
