# Weekly Release Report for vllm-project/vllm (2026-11-13)

This week merged 584 PRs from 260 contributors. Key areas: features 0, fixes 127, performance 52.

## Executive Summary

本周发布主要围绕硬件后端与模型支持扩展：新增面向 batched MoE 的 XPU all-to-all Expert-Parallelism 后端，Mamba2 ReplaySSM 投机解码现可在 Triton 后端运行，CPU 算子封装迁移至 vllm/_cpu_ops.py；Kimi K3.1 引入模型文件与 NVIDIA 专用 decode 路径，Kimi K3.1 Pro 补充 ROCm DCP、P/D 与 indexer top-k 支持。修复覆盖范围较广，涉及 engine 启动失败时的 executor 关闭、引擎退出时 CUDA graph 全局池重置、DeepGEMM 版本升级、KV offload 与 KV connector 的状态一致性、启动期 SIGTERM 处理、PCP 下的 M-RoPE 位置准备、pipeline parallel 各阶段 CUDA graph padding 差异，以及 ROCm AITER 算子路由等。

性能方面包含减少 host 同步、规避运行时 JIT 与权重连续性处理等改进。本期未发现明确的 breaking change 或强制升级步骤，建议升级后重点回归 MoE、KV offload、投机解码及多模态长上下文场景，并关注 XPU、ROCm 平台上的后端行为差异。
