# Weekly Release Report for vllm-project/vllm (2026-10-09)

This week merged 404 PRs from 230 contributors. Key areas: features 1, fixes 122, performance 35.

## Executive Summary

本周发布以稳定性与跨硬件性能调优为主线，并补充前端与多模态能力。新增 Python 与 Rust frontend 的 per-session profiling 控制，Transformers backend 支持 video 输入，并引入 watermark 兼容性校验。性能方面，针对 Intel B70 调优 Triton W8A8 block-FP8 GEMM，新增 ROCM_SEGMENTED_ATTN attention backend，覆盖 RDNA3/3.5/4，同时修复 HiSparse/MTP 等路径问题。

修复范围较广，涉及 tool parser、frontend 流式与 batch 行为、KV connector（NIXL、Mooncake）、Prefix caching/hybrid Mamba、structured output、MoE/LoRA、spec decode、ROCm attention，以及 Qwen3-VL、Qwen4Exp、GLM-5.3、MiniMax、DeepSeek V4 等模型路径，并修复 x86 docker build。升级注意：tokenizers 升至 0.23.2，启动时会校验 tool-parser/tokenizer 兼容性，watermark 配置需通过兼容性验证；wheel 不再声明 flashinfer-jit-cache。未见明确破坏性变更，但建议对 KV、ROCm 与量化相关路径回归验证后升级。
