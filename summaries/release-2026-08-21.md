# Weekly Release Report for vllm-project/vllm (2026-08-21)

This week merged 286 PRs from 164 contributors. Key areas: features 3, fixes 72, performance 12.

## Executive Summary

本周 vLLM 版本主要围绕模型支持扩展、推理正确性与后端稳定性展开。新增 CPU 平台 AMX-only 高性能 MLA backend，面向 DeepSeek V2/V3/R1；新增 Muse Glimmer、NemotronH_Omni_Reasoning_V3 以及 DSpark/DeepSeek V4 相关模型支持。同时合并多项对 Gemma、Qwen3.5/3.6、Kimi-K3、Mamba、HunyuanOCR 等架构的修复，涵盖 speculative decoding、structured output、LoRA、量化及 multimodal 处理等场景。API 前端层面修正了多项状态码与参数校验行为，并修复 api_key 日志泄露问题；`api_server.py` 已从 openai 目录移出，相关路径引用可能需调整。

性能方面，重点包括 ROCm 下 DeepSeek-V4 mHC post/pre 与 RMSNorm 的 AITER 融合，以及 CPU 非 AMX 平台的 causal_conv1d 路径启用；另有若干硬件相关修复，覆盖 XPU、ROCm、RISC-V 与 SM120。升级时需注意 DeepSeek-V4 的 eager/cudagraph 区域选择、FlashInfer 相关 attention backend probe 行为、以及前端 generate 路由对 n>1 的处理变更。整体无重大破坏性 API 变更，但建议关注路径迁移与模型专属配置调整。
