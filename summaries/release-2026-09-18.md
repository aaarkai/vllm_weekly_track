# Weekly Release Report for vllm-project/vllm (2026-09-18)

This week merged 445 PRs from 225 contributors. Key areas: features 1, fixes 118, performance 29.

## Executive Summary

本周 vLLM 发布聚焦 DSv4.1 与多硬件支持、KV cache/offload 与 spec decode 稳定性，以及前端与 CI 修复。重点特性包括 Rust Frontend 原生 renderer reasoning controls 规范化、DSv4.1 FlashMLA mega attention 与 NVFP4 compressed KV cache、Engram 异步预取及 DP sharding。修复覆盖 DeepEP 低延迟 profiling 崩溃、ROCm GLM-5.3-Flash 启动异常、KV Connector 与 MTP 死锁、FlashMLA workspace 释放、CPU FP8 与 DeepSeek-R1 正确性及 Responses/beam search 等。性能工作集中在 CUDA graph 分歧收敛与 FlashInfer BF16 autotuning 隔离。

升级注意：--tokens-only 服务将拒绝 stop strings，pip install 版本报告已修正；建议升级前回归 ROCm、KV offload、spec decode 与多模态负载。
