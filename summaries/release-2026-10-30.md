# Weekly Release Report for vllm-project/vllm (2026-10-30)

This week merged 584 PRs from 282 contributors. Key areas: features 0, fixes 143, performance 57.

## Executive Summary

本周发布主要集中在新模型接入与后端能力扩展。新增 MiniMax-M3.1-Flash 模型及其 kernels，并支持 Muse Spark Open；Kimi K3 引入 KDA RecoverSSM 的 CuTe verify 与 commit kernels，并将 records 移出 KV cache。ROCm 侧新增原生 3-bit KV cache 后端 Octave KV（ROCM_OCTAVE），同时支持通过在线量化实现 NVFP4 MoE 重量化与 fused shared experts。

修复以 KV Offload（含 P2P、OBJ）的握手、超时处理、槽位释放与分块对齐为主，另覆盖 Rust Frontend、GLM-4.7 流式工具调用参数解析、多模态 processor 缓存命中、speculative decoding、CUDA Graph、NVFP4 未初始化 scale 导致的 NaN logits，以及 CPU、XPU、ROCm 后端问题。本周未声明 Breaking Change；建议使用 KV Offload、ROCm 与 Rust Frontend 的部署进行升级，并注意 vllm-bench 现已拒绝 `--max-concurrency 0`。
