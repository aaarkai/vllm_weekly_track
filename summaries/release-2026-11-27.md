# Weekly Release Report for vllm-project/vllm (2026-11-27)

This week merged 538 PRs from 256 contributors. Key areas: features 0, fixes 125, performance 44.

## Executive Summary

本周发布聚焦运行时接入、模型兼容性与稳定性。Fast Start 为 preload daemon 增加 VMM IPC 后端；ReplaySSM 缓存 SSM 输入以加速 Gated DeltaNet 标准解码；Transformers 后端增加 Omni 支持；Rust Frontend 统一调度指标分组与请求校验，并退役 validator。修复覆盖 multimodal、KV cache/offload、Transformers 后端、ROCm 以及 Kimi、DeepSeek、Inkling 等模型路径，同时限制同步媒体请求体大小，并处理若干死锁、竞态与精度问题。

性能与硬件适配涉及 ReplaySSM、Inkling 2 在 SM12x 的 TMA 路径，以及 SM8x 相对注意力、SM90 MXFP8、ROCm int8 和 FlashInfer CUTLASS 修正。未发现其他明确 breaking change；升级时建议重点回归 Rust Frontend 的 validator 移除与请求校验变更，并验证相关模型、KV cache/offload 及多模态链路。
