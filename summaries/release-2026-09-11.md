# Weekly Release Report for vllm-project/vllm (2026-09-11)

This week merged 317 PRs from 180 contributors. Key areas: features 1, fixes 80, performance 29.

## Executive Summary

本周发布引入 DeepSeek-V4 CPU backend、Diamond Rapids 原生 AMX-FP8 attention、水印生成与检测（Gumbel-max），以及 P2P NIXL + CPU EC Connector；AutoRound 格式新增 2/3/5/6/7 CUDA 支持。修复覆盖 multimodal、ROCm、XPU、frontend、KV offload、spec decode、MoE、LoRA 等路径，并处理多处内存访问、缓存恢复、预热与序列化边界问题。性能方面，ROCm multi-stream、NVFP4 KV、CUTLASS workspace 等得到优化。

升级注意：GPTQ Group/Dynamic Activation Ordering 已被移除，使用相关量化权重的部署需在升级前验证兼容性；其余变更未列出明确 breaking change，建议按常规流程回归测试 CPU、ROCm、XPU 及多模态场景。
