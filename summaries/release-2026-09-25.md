# Weekly Release Report for vllm-project/vllm (2026-09-25)

This week merged 389 PRs from 194 contributors. Key areas: features 1, fixes 93, performance 29.

## Executive Summary

本周发布聚焦 Model Runner V2、量化与内核路径扩展：新增 custom logits processors，支持 DiffusionGemma 的 structured generation，并加入 one-step recipe serving；Kernel 侧完成 MXFP8 wo_b GEMM 与 sequence-parallel reduce-scatter 融合，Marlin 与 Humming 共享 persistent workspaces。命名与依赖同步至 Transformers v5，并移除冗余 processor use_fast 参数。修复覆盖 frontend reasoning token 统计、Outlines EOS 终止、MRV2 sampler JIT warmup、full logprobs、Whisper 长音频、MLA sparse prefill、KV offload、spec decode，以及 ROCm、XPU、CPU 多类问题；量化侧更新 Humming kernels 与 NVFP4 scales。

升级前应验证 Transformers v5 兼容性、Humming kernels 依赖版本，以及 ROCm/AITER、DeepEP、DP+EP+DBO 等部署配置。本次未明确列出独立 breaking change；相关 kernel、量化和硬件后端变动可能影响既有配置，建议按目标平台回归测试。
